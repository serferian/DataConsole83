# Проверка DataConsole83

Проверяй решение независимо от заявленного результата. Файлы при ревью не изменяй.

## Статическая проверка

1. Прочитай `docs/project-index.md` и итоговый diff, отделив посторонние изменения.
2. Для BSL проверь директивы клиент/сервер, сигнатуры обработчиков, запросы, временное хранилище, фоновые ветки и безопасный режим.
3. Для UI найди все BSL-вызовы затронутого JavaScript API, DOM-идентификаторы и порядок RequireJS-загрузки.
4. Сравни состав и SHA-256 файлов `src/code/` с ZIP `Templates/src/Ext/Template.bin`; несовпадение допустимо только если явно объяснено.
5. Выполни `git diff --check`. Для сборки проверь exit code и время/наличие артефакта.

## Динамические сценарии

Выбери минимальный набор, различающий варианты: загрузка и повторное открытие Monaco; обычный и пакетный запрос; пустой результат; ошибка запроса/BSL с позиционированием; клиентское, серверное и при необходимости фоновое выполнение; просмотр вложенной таблицы или хранилища. Оформи UI-проверки как BDD «дано/когда/тогда».
