# Индекс проекта DataConsole83

Состояние индекса: 14 сентября 2026 года.

## Назначение

**Консоль запросов для 1С с редактором на базе Monaco** — внешняя управляемая обработка `DtCons83Monaco`. Она хранит дерево алгоритмов, выполняет запросы и произвольный BSL-код на клиенте, сервере или в фоне, показывает результаты и временные таблицы, а Monaco обеспечивает подсветку, подсказки, навигацию, форматирование и отображение ошибок.

Версия в метаданных обработки: `5.0.6`. Исходные проекты, указанные в комментариях кода: `dtcons83.epf` и `bsl_console`.

## Ключевые потоки

### Запуск редактора

1. `ПриСозданииНаСервере` помещает макет `src` во временное хранилище.
2. Клиентская инициализация записывает пакет как `bsl_console.zip`, извлекает файлы и загружает `index.html` в поля HTML-документа.
3. `ИнициализацияРедактора` связывает форму с JavaScript API. `View()`, `QueryView()` и `CodeView()` возвращают `defaultView` соответствующего HTML-документа.
4. `ОбработатьСобытиеРедактора` принимает события Monaco и переносит состояние в форму 1С.

### Выполнение

- Команды `ВыполнитьЗапрос*` передают текст в серверный контур, формируют результаты и адреса временного хранилища.
- `ВыполнитьКод` маршрутизирует BSL между клиентом, сервером и фоновым выполнением. Код с объявлениями методов, директивами компиляции или препроцессора выполняется во временной EPF: серверная страница — через объектный модуль, клиентская — через модуль служебной управляемой формы. Линейный код сохраняет прежний путь через `Выполнить()`.
- `ОбработатьРезультатВыполнения`, `ОбновитьФорму` и `ОтобразитьРезультатВременнойТаблицы` обновляют UI и диагностические данные.

## Инварианты и риски

- `src/code/` — редактируемые web-исходники, а `Templates/src/Ext/Template.bin` — исполняемый runtime-пакет. Для workbench источником истины служат `index.html`, `editor.js`, `workbench.js` и `workbench.css` из `src/code/`; в runtime-пакете 59 файлов. Существующее расхождение `bsl_helper.js` с рабочей копией пока сохраняется, поэтому пакет обновляется выборочно. `src2` считается справочным вариантом и без отдельного решения не синхронизируется.
- Изменение имени JavaScript-функции, события или DOM-элемента требует проверки вызовов из BSL и HTML.
- Обработка выполняет произвольный код. Нельзя ослаблять безопасный режим, расширять контекст выполнения или выводить секретные значения без отдельного решения по безопасности.
- Объектный модуль и модуль формы временного исполнителя ограничены отдельными фиксированными слотами примерно по 256 КБ. `Template.bin` нужно пересобирать скриптом `tools/buildCodeExecutorTemplate.ps1`, а не редактировать вручную.
- Жизненный цикл временных файлов и адресов хранилища должен завершаться очисткой и корректно работать при повторной инициализации.
- `src/code/test.html` ссылается на отсутствующий `test.js`; готового автоматического web-test runner нет.
