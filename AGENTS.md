# Repository Guidelines

## Структура проекта

Это внешняя обработка 1С `DtCons83Monaco` (версия метаданных 4.0.0), совмещающая консоль запросов, выполнение BSL-кода и Monaco Editor. Распакованные XML-исходники обработки находятся в `src/epf/DtCons83Monaco/`. Главная точка оркестрации — `Forms/Основная/Ext/Form/Module.bsl`; объектный модуль регистрирует внешнюю обработку. Web-интерфейс редактора хранится в `src/code/`, а исполняемый пакет внутри EPF — в `Templates/src/Ext/Template.bin`. Перед изменением интерфейса прочитайте `docs/project-index.md` и проверьте синхронизацию этих двух представлений.

## Сборка и разработка

Репозиторий рассчитан на Windows, OneScript и `vanessa-runner`; файловая служебная ИБ — `.build/ibservice`.

```powershell
tools\compileEpfErf.cmd src\epf\DtCons83Monaco
tools\decompileEpfErf.cmd ".build\DtCons83Monaco.epf"
git diff --check
```

Скрипты используют устаревшие команды `vrunner compileepf/decompileepf`. У установленного `vanessa-runner 3.x` актуальны `vrunner epf compile/decompile`; не считайте сборку успешной без проверки exit code и наличия артефакта.

## Стиль и границы изменений

BSL пишите по-русски, сохраняйте клиент-серверные директивы, области, табуляцию и управляемый режим. Не меняйте XML формы вручную без проверки соответствия обработчиков модулю. Для JavaScript сохраняйте текущий AMD/RequireJS-контракт, публичные функции `window/defaultView` и совместимость с HTML-документом 1С. Не редактируйте vendored `src/code/vs/` без отдельной задачи. DDD применяйте к новым обособленным подсистемам, не имитируя слои внутри одной формы.

## Проверка и ревью

Автоматизированный тестовый контур в репозитории не настроен. Для изменений BSL нужны сценарии выполнения запроса/кода и вывода результата; для UI — BDD-проверка загрузки Monaco, редактирования, событий и ошибок в целевых клиентах 1С. Не объявляйте тесты пройденными по одному exit code. При ревью сначала проверяйте факты по обоим слоям, затем ищите сценарий отказа; блокирующие замечания отделяйте от рекомендаций.

Коммиты следуют истории репозитория: `feat:`, `fix:`, `refactor:` и краткое русское описание. Не включайте `.build`, `.vscode`, EPF/ERF и посторонний пользовательский diff.
